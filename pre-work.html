2.1 Setup, Download, and Install Cursor

Cursor is a code editor with built-in AI. You describe what you want, and Cursor writes the code.

One-Year Free Cursor Pro For Students:

Eligible students get one free year of Cursor Pro, including $20 of usage per month. Cursor Pro gives you a set amount of AI usage each month (the $20 credit). When you use the AI to edit code, ask questions, or generate content, that usage counts against this amount. For most students, the included $20 per month is enough. If you want to exceed it, you can turn on usage-based pricing (disabled by default)—you pay for the extra usage.

To get the free year of Cursor Pro, you need to sign up for the student discount. Create your Cursor account using your valid .edu university email—this is required. Your Cursor account email must match this .edu email, and you must use the same email when you verify your student status.

Step 1: Create an account at Cursor.com

Do this before downloading the app. To take advantage of Cursor's free student program, you must create an account at Cursor.com with your valid .edu university email address, and submit proof of your current enrollment (e.g. a picture of your student ID). Follow the directions at cursor.com/students carefully:

  1. On the Cursor website, click Sign In in the upper-right corner, then continue through the steps to create a new account (use your .edu email).
  2. Once you are logged in, click Settings (look for the gear icon on the left), then open the link for Student Status under "Student Verification".
  3. This takes you to a third-party site where you upload the required documentation. Complete the verification process.

Step 2: Download and install the Cursor app

  1. Go to cursor.com/students
  2. Click Download and choose your operating system (Mac, Windows, or Linux)
  3. Install the application on your computer
  4. Once installed, open the app and go to Cursor → Settings → Cursor Settings… then click Open under "Manage Account". This opens your browser where you log in to the account you created in Step 1. That links the app to your student status so you get the free Cursor Pro benefits.

2.2 Create an Account at GitHub.com

GitHub is where developers store and share code. It's also your portfolio—recruiters and hiring managers look at GitHub profiles.

Step 1: Create an account at GitHub.com

  1. Go to github.com and click "Sign up".
  2. Use your school email (this unlocks student benefits)
  3. Choose a professional username—this will be visible to employers
    • Good: jsmith, jane-smith, jsmith2027
    • Avoid: xX_codemaster_Xx, partyanimal99
  4. Complete the verification steps

Step 2: Connect Cursor to your GitHub account

Connecting Cursor to your GitHub account is how you move your projects from you computer to the internet. Do the following:

  1. Log in to your account on the Cursor website.
  2. Go to your account settings and find the Integrations or Tools & Integrations tab.
  3. Click Connect GitHub. You will be prompted to sign into your GitHub account if you aren't already.

2.3 Install And Configure Git

Your computer uses Git to track changes in your code and upload it to GitHub. Think of it like "track changes", but for code.

To Install Git on Mac:

  1. Open Terminal (search for "Terminal" in Spotlight, or find it in Applications → Utilities)
  2. Type git --version and press Enter. If you see a version number (e.g. git version 2.x.x), Git is already installed—you're done.
  3. If Git is not installed, install it by running the Xcode Command Line Tools installer. In Terminal, type xcode-select --install and press Enter.
  4. A dialog will appear asking to install the command line developer tools. Click "Install" and wait for the installation to finish.
  5. When it's done, run git --version again to verify. You should see a version number.

To Install Git on Windows:

  1. Go to git-scm.com
  2. Download the Windows installer
  3. Run the installer, accepting the default options
  4. Open Command Prompt and type git --version to verify

Important: Configure Git

After installing, open Terminal (Mac) or Command Prompt (Windows) and run these two commands, replacing with your actual name and email:

git config --global user.name "Your Name"
git config --global user.email "your.email@school.edu"

Think of this as your signature, so GitHub knows who you are.
